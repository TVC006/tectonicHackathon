# KBC SHIFT

> From personalized banking to situational banking.

Hackathon proof of concept — not a production banking app.

## Run

```bash
node server.js
```

Open [http://localhost:3000](http://localhost:3000).

No install. No env vars. No network required for the hero demo.

## 60-second demo

1. Emma's normal account — rental deposit, IKEA, Brico, Cambio
2. **Connect the signals** → Moving 91%
3. Confirm **Are you moving?**
4. **Moving Mode** opens
5. **Review standing order** → **Pause payment**
6. **Continue setup** → address updated
7. Show persona strip: one engine, millions of situations

Demo controls (bottom-right): **Reset demo** · **Skip to Moving Mode**
